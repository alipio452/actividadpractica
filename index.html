Eventos con JavaScript

Esta página demuestra cinco eventos diferentes de JavaScript.

1. Evento click

Presiona el botón para cambiar el mensaje.

Aquí aparecerá el resultado.

2. Evento mouseover

Pasa el cursor por encima de la tarjeta.

Pasa el cursor aquí

Todavía no has pasado el cursor.

3. Evento input

Tu saludo aparecerá aquí.

4. Evento change

El color cambiará cuando elijas una opción.

5. Evento submit

Completa el formulario y envíalo.

Tu comentario aparecerá aquí.
